======================================================
  COM USAR L'ASSISTENT DE COMPRA BONPREUESCLAT
======================================================

REQUISITS PREVIS (fer una sola vegada):
----------------------------------------
1. Tenir Python 3.8 o superior instal·lat
2. Executar a la terminal:

   pip install -r requirements.txt
   playwright install chromium

CONFIGURACIÓ DE LES CREDENCIALS (opcional):
--------------------------------------------
1. Copia el fitxer .env.example i anomena'l .env:
   cp .env.example .env

2. Edita .env amb el teu email i contrasenya d'Esclat Online

   (Si no fas això, pots iniciar sessió manualment al navegador
    quan s'obri)

COM EXECUTAR:
--------------
Opció A - Mode interactiu (t'anirà preguntant):
   python compra_esclat.py

Opció B - Passar productes directament:
   python compra_esclat.py "llet desnatada" "pa de motlle" "ous" "tomàquets"

QUÈ FA EL PROGRAMA:
---------------------
1. Obre el navegador Chrome automàticament
2. Va a BonpreuEsclat Online
3. Inicia sessió (amb .env) o espera que ho facis tu
4. Per cada producte:
   - Fa la cerca
   - Et mostra fins a 5 resultats amb preu
   - Tu tries quin vols afegir (o el saltes)
5. Al final obre el carro per que confirmes la comanda

IMPORTANT:
-----------
- La comanda final la confirmes tu al navegador
- El programa mai fa la comanda sense la teva confirmació
- Les credencials es guarden NOMÉS al teu ordinador (.env)

======================================================
  COM USAR L'ACCÉS ALS ENVIAMENTS DE MRW
======================================================

CONFIGURACIÓ (fer una sola vegada):
------------------------------------
1. pip install -r requirements.txt
   playwright install chromium

2. Copia .env.example a .env i posa-hi el teu usuari i
   contrasenya de l'àrea de clients de MRW:

   MRW_USUARI=el_teu_usuari@exemple.com
   MRW_CONTRASENYA=la_teva_contrasenya

   El fitxer .env NO es puja mai al repositori.

COM EXECUTAR:
--------------
   python enviaments_mrw.py                       -> llista els enviaments
   python enviaments_mrw.py 0012345678            -> seguiment d'un enviament
   python enviaments_mrw.py --csv enviaments.csv  -> exporta el llistat a CSV
   python enviaments_mrw.py --login               -> força tornar a iniciar sessió
   python enviaments_mrw.py --headless            -> sense finestra de navegador

QUÈ FA EL PROGRAMA:
---------------------
1. Obre el navegador i va a l'àrea de clients de MRW
2. Accepta el bàner de cookies si apareix
3. Inicia sessió amb les dades del .env
   - Si no ho aconsegueix (per exemple si hi ha un captcha),
     s'atura i et deixa iniciar sessió tu mateix a la finestra
4. Guarda la sessió a .mrw_sessio.json per no haver de tornar
   a entrar cada vegada (esborra'l amb --login si cal)
5. Busca el llistat d'enviaments i el mostra per pantalla
6. Opcionalment ho desa tot en un CSV separat per punt i coma

IMPORTANT:
-----------
- Els selectors de la web de MRW són aproximats: si la pàgina
  canvia, el programa et deixarà navegar manualment i llegirà
  la taula que tinguis a la pantalla.
- Les credencials es guarden NOMÉS al teu ordinador (.env)
