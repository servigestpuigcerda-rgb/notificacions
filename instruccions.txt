======================================================
  COM USAR L'ASSISTENT DE COMPRA BONPREUESCLAT
======================================================

REQUISITS PREVIS (fer una sola vegada):
----------------------------------------
1. Tenir Python 3.8 o superior instal·lat
2. Executar a la terminal:

   pip install -r requirements.txt
   playwright install chromium

CONFIGURACIÓ DE LES CREDENCIALS (opcional):
--------------------------------------------
1. Copia el fitxer .env.example i anomena'l .env:
   cp .env.example .env

2. Edita .env amb el teu email i contrasenya d'Esclat Online

   (Si no fas això, pots iniciar sessió manualment al navegador
    quan s'obri)

COM EXECUTAR:
--------------
Opció A - Mode interactiu (t'anirà preguntant):
   python compra_esclat.py

Opció B - Passar productes directament:
   python compra_esclat.py "llet desnatada" "pa de motlle" "ous" "tomàquets"

QUÈ FA EL PROGRAMA:
---------------------
1. Obre el navegador Chrome automàticament
2. Va a BonpreuEsclat Online
3. Inicia sessió (amb .env) o espera que ho facis tu
4. Per cada producte:
   - Fa la cerca
   - Et mostra fins a 5 resultats amb preu
   - Tu tries quin vols afegir (o el saltes)
5. Al final obre el carro per que confirmes la comanda

IMPORTANT:
-----------
- La comanda final la confirmes tu al navegador
- El programa mai fa la comanda sense la teva confirmació
- Les credencials es guarden NOMÉS al teu ordinador (.env)

======================================================
  ENVIAR UN SMS D'AVÍS AMB MRW (mrw_sms.py)
======================================================

QUÈ FA:
--------
Es connecta a l'API oficial de MRW (servei web SAGEC), dóna d'alta un
enviament i activa la NOTIFICACIÓ per SMS. MRW envia automàticament
l'SMS d'avís al mòbil del destinatari.

CONFIGURACIÓ (fer una sola vegada):
------------------------------------
1. Demana a MRW l'accés al servei web SAGEC. Et donaran:
   franquícia, codi d'abonat, usuari i contrasenya.
2. Posa aquestes dades al fitxer .env:
   MRW_FRANQUICIA, MRW_ABONAT, MRW_USUARI, MRW_CONTRASENYA

COM EXECUTAR:
--------------
   python mrw_sms.py \
       --nom "Joan Garcia" \
       --telefon "600123456" \
       --via "Carrer Major" --numero "10" \
       --cp "17520" --poblacio "Puigcerdà"

OPCIONS ÚTILS:
---------------
   --tipus-avis 1   Avís quan es crea l'enviament (emissió)
   --tipus-avis 3   Avís el dia del repartiment (per defecte)
   --proves         Fa servir l'entorn de proves de MRW (sagec-test)
   --referencia     Referència interna de l'enviament
   --codi-servei    Codi de servei MRW (per defecte 0005)

NOTA:
------
- Els codis de servei i de tipus de notificació poden variar segons
  el teu contracte amb MRW. Confirma'ls amb el manual d'integració SAGEC.
